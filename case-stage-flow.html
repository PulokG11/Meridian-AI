Flowchart of the 9 case stages (0 through 8) in Meridian AI and the commands that move a case from one stage to the next

Stage is never stored — api.case_stage(case_id) derives it live from the claim/denial/appeal/records_request/remittance/deposit rows each time it's called. Stage 8 (closed) can return to an earlier stage via case.reopen (a payer takeback/recoupment), which is why the diagram shows a reopen edge back into the loop rather than a dead end.
